Vector databases and similarity indexes are used in RAG systems to retrieve text chunks that are semantically similar to a query. After text chunks are converted into embeddings, those embeddings are stored in a structure that supports nearest-neighbor search.
FAISS is a widely used open-source similarity search library. It is efficient for dense vector retrieval and is commonly used in local RAG systems. Chroma is another popular option that provides a more database-like developer experience for storing and querying embeddings.
The core idea is that semantically similar texts will have embeddings that are close to each other in vector space. When a user submits a question, the system embeds the query and searches for nearby vectors. The top matching chunks are then returned to the generation model as context.
Good retrieval depends on both the embedding model and the indexing method. If retrieval returns irrelevant chunks, the final answer may be incomplete or incorrect even if the language model itself is capable.
