Retrieval-augmented generation, or RAG, is a system design pattern that combines document retrieval with language generation. Instead of relying only on the language model's internal knowledge, a RAG system first retrieves relevant information from an external document collection and then uses that information to generate an answer.
A typical RAG pipeline has several components. First, documents are collected and prepared. Second, the documents are split into smaller chunks. Third, embeddings are created for each chunk. Fourth, those embeddings are stored in a vector database or similarity index. Fifth, when a user asks a question, the system embeds the query and retrieves the most relevant chunks. Finally, the retrieved context is inserted into a prompt for a language model, which generates an answer grounded in the retrieved evidence.
RAG is useful because it can reduce hallucination and improve factual accuracy. It also allows the system to use up-to-date or domain-specific information without retraining the model. However, the quality of a RAG system depends heavily on chunking quality, retrieval quality, and whether the model follows the instruction to stay grounded in the provided context.
